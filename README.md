
# Investigation into Body Mass Index in Scotland Using the Scottish Health Survey

## Overview
This project is an investigation into Body Mass Index (BMI) in Scotland using 
data from the Scottish Health Survey (2008 to 2012). The aims were to determine
whether the BMI in Scotland had changed between 2008 and 2012 and also to assess
if there were any differences in the BMI distribution by demographic, 
socio-economic, and lifestyle factors.

## Data
The data set includes the following variables:
- BMI
- Age Group
- Sex
- Status of Employment
- Fruit Intake
- Vegetable Intake
- Year

## Method
The analysis included:
- Exploratory analysis
- Multiple linear regression
- Backward model selection
- Model diagnostics

## Key Findings
- No evidence of a change in BMI between 2008 and 2012
- BMI generally increased with age, peaking at 55-64
- Individuals unable to work had a higher BMI on average
- Individuals in full-time education had a lower BMI on average
- Individuals who consumed the recommended vegetable intake had a lower BMI on 
  average
